Hak akses setiap role
Admin
Admin dapat:
- melihat semua tiket;
- membuat, mengubah, dan menghapus tiket;
- mengatur status tiket;
- menetapkan teknisi;
- mengelola user;
- mengelola kategori;
- melihat dashboard;
- melihat laporan;
- mengakses log aktivitas;
- mengubah pengaturan aplikasi.

Teknisi
Teknisi dapat:
- melihat tiket yang ditugaskan;
- melihat detail tiket;
- mengubah status tiket;
- menulis komentar;
- menulis solusi;
- mengunggah bukti pekerjaan;
- menandai tiket selesai.

Teknisi tidak boleh:
- menghapus user;
- mengubah role admin;
- menghapus seluruh tiket;
- mengubah konfigurasi keamanan.

User/Pelapor
User dapat:
- membuat tiket;
- melihat tiket miliknya;
- memberi komentar;
- menambahkan informasi;
- mengunggah foto atau bukti;
- membatalkan tiket miliknya sebelum ditangani;
- mengonfirmasi bahwa masalah selesai.

User tidak dapat:
- melihat tiket karyawan lain;
- menetapkan teknisi;
- mengubah role;
- melihat dashboard internal;
- menghapus tiket milik orang lain.
